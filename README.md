# 👁️ SuperVision — AI Vision Assistant

SuperVision is a private, offline AI assistant powered by Google's Gemma model.
All AI processing happens directly on your device — no data sent to the cloud.

## ✨ Features
- 🤖 On-device AI chat (no internet required after setup)
- 📷 Camera vision — ask AI what it sees
- 🎙️ Voice input & text-to-speech
- 📝 OCR — read text from images
- 🌙 Dark silver UI theme
- ♿ Full accessibility support

## 📱 Requirements
- Android 7.0+
- 6GB+ RAM
- 5GB free storage (for AI model)

## 🚀 Getting Started

### Prerequisites
- Flutter SDK 3.8+
- Android Studio
- HuggingFace account (free)

### Installation
```bash
git clone https://github.com/vishnuprasadgs/supervision-app.git
cd supervision-app
flutter pub get
flutter run
```
